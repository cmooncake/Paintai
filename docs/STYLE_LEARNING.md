# 参考图学习与风格档案

在网页选择画师 → 学习 →「参考图与风格档案」。上传参考作品，选择 1–3 张，填写档案名称并点击「提取所选作品的画风」。当前视觉评价模型接收实际图片，提取配色、线条、光影、构图、质感和创作指导。任务使用持久化队列，关闭网页仍会执行。

提取结果保存为草稿，检查并修改后点击「保存并启用风格档案」。每次编辑保存生成一个新版本，可以选择以前的档案重新启用，也可停用。未启用的草稿不影响创作。只有当前画师能使用其参考图和档案。

单张图可能包含偶然的题材或角色特征，不能代表画师全部风格。建议选取具有共同画风、不同题材的作品，并审核模型是否把发色、服装、背景误当成必须复制的规则。当前是参考图视觉分析与提示词引导，不是模型权重训练，也不保证准确复现画风。

## 图片与模型

- 支持 PNG、JPEG、WebP，每张最多 10 MB、2500 万像素；每位画师最多保存 30 张。
- 后端校验并解码图片、处理方向，清除元信息，缩至最长边 768 像素，以 PNG 保存。哈希记录针对实际传给模型的标准化图片。
- 图片保存在本机 `data/painters/<id>/references/`，记录与档案保存在 SQLite。前端通过专用图片接口访问，不获得本机路径。
- 分析使用提交任务时冻结的视觉模型配置。选择远程视觉服务时，选中的参考图会发送到该服务；本地视觉模型则使用本机推理。
- 模拟模型不能生成风格档案。无效 JSON、接口失败或中断不会产生虚假档案，也不会修改当前已启用档案。

## 如何影响后续流程

画师配置保存当前风格档案，普通创作、课程练习和成长实验提交时冻结画师快照。构思和评价的 `art_brief.style_profile` 包含档案版本、提取特点、参考图 ID 和哈希；具体创作题材与本轮要求优先于参考图的角色、物体等内容。

生图使用包含风格要求的构思提示词，不直接将参考图作为图生图输入。评价模型查看新作品图片，并按冻结的风格描述评价实现和偏差；本版本不是参考图与作品并排的视觉相似度测量。

创作记忆记录同一份 `art_brief`，网页作品详情、练习记录和记忆显示档案名称、版本及指导条目。经验蒸馏也按该创作要求分组。旧作品重评沿用其原始档案，不受后续编辑影响。参考学习任务本身不计入课程过关或作品评分。

## API

- `POST /api/v1/painters/{id}/references`：请求体为原始图片字节；返回参考图 ID、尺寸、哈希与图片 URL。
- `GET /api/v1/painters/{id}/references/{reference_id}/image`：已归属该画师的标准化图片。
- `GET /api/v1/painters/{id}/styles`：参考图列表、档案版本和当前启用版本。
- `POST /api/v1/painters/{id}/styles/analyze`：`name`、`reference_ids`，需 `Idempotency-Key`；返回队列任务，通过 `/jobs/{id}` 查询。
- `POST /api/v1/painters/{id}/styles/activate`：`profile_id`，可带修改后的 `name`、`traits`；`profile_id: null` 停用。执行任务时暂不允许切换档案。

## 验证

### 原题属性保护

英文生图模式不再把风格档案、长期目标或历史建议自由改写后直接追加。模型只能从有限绘画技巧中选择最多四项（如细线条、柔和面部阴影、虹膜细节和发丝高光）；其中不包含角色颜色、服装、背景或画师姓名。原题与本轮明确要求保留，不能被风格档案覆盖。这会牺牲部分配色和构图迁移自由度，以优先保证题目服从。

本地生图对明确可识别的英文单色头发、眼睛、服装和背景描述前置并加权（1.25–1.5），并在简短的负面提示词中排除常见冲突项。使用运行器支持的 [token weighting](https://github.com/leejet/stable-diffusion.cpp#features)。琥珀色眼睛补充金橙色虹膜，米白衬衣补充白色衬衣同义描述。`generation_constraints` 保存提取到的属性和实际负面提示词，网页作品详情「查看创作构思」可查。未识别的描述不会凭空补齐；这是提示词约束，不是像素级硬保证，仍需逐项视觉验收。

风格实验两组使用相同原题、模型、种子和属性保护，同时关闭旧记忆和长期目标的生图提示注入，仅学习组加入风格档案技巧。长期目标仍保留在画师和实验快照中，不修改用户设置。两组若得到相同提示词，结果会明确标为无法比较学习效果，不把模型评分波动误当作成长。

自动化覆盖上传大小与格式校验、画师隔离、实际图片传递、提取失败不发布档案、重复请求、审核版本不可变、排队快照、创作/评价/记忆传递与停用后历史保留。
