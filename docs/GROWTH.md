# M2a 经验蒸馏与成长对照

这一阶段实现研究执行文档 Phase 2a 的简化经验蒸馏，以及固定题目的有经验 / 无经验对照。没有训练模型权重，也没有实现完整 VED、向量检索或课程顺序消融实验。

## 网页入口

选择画师 → 学习 → 成长实验。

1. 「整理并蒸馏历史经验」会检查最近 2000 幅已完成作品。后续普通创作或课程作品完成评价时，也会自动更新候选规则。
2. 展开候选规则查看高低分来源、评分、原始构思及评价。没有符合条件的作品时显示空状态，不制造规则。
3. 输入固定题目，选择 1、3、5 或 10 对（分别生成 2、6、10、20 幅）。预览即将使用的目标、模型配置与经验，再开始实验。题目最好取自已练习的主题；无相关真实记忆时拒绝启动。
4. 实验记录展示配对曲线、六维差异、胜平负及并排作品，点击图片可查看完整评价、构思和实际经验引用。

## 蒸馏边界

当前方法 `best_worst_extract_v1` 是可追溯的**抽取式蒸馏**，无需新增模型调用：

- 按完全相同的题目、风格快照、艺术要求、已记录模型配置、评价量表和流水线版本分组。不同题目变体不会被当作同题证据；当前配置包含生图种子，因此跨种子的历史作品也不会被合并。
- 排除模拟作品、未完成作品、实验作品。至少两个样本且均分差 ≥ 0.25 才形成候选。
- 选最高分 / 最低分作品，保存 `what_worked`、`what_failed`、逐维分差及原始生图提示词；将高分作品的构图作为待验证候选，结合低分作品的改进建议提取两条可执行规则。
- 同组候选会随重评更新；没有分差时撤下当前候选。旧作品或旧实验中已经引用的经验快照不变。
- 规则通过现有本地文本 / 技能检索进入构思。相关性相近时优先候选规则；低相关性规则不会仅凭蒸馏身份压过明显更相关的普通经验。
- 这是反馈与轨迹的结构化整理，不是额外视觉判官重审，也不证明某条构图建议造成了分数差。旧作品缺少流水线版本时单独归为 legacy；无法追溯当时服务端模型权重是否变化。

完整高低分证据保留在数据库。实际注入仍遵守小模型上下文预算：最多 `memory_top_k` 条经验，每条前两条规则、每条最多 160 字。

## 实验协议

`frozen_memory_ab_v1` 对比的是同一个画师在当前条件下**关闭记忆的基线**与**使用当前冻结经验**，不是将日期早晚不同的作品直接相减。

- 题目、风格、长期目标、模型和参数在提交队列时冻结。预览不收费、不生成作品；提交时最终快照可在记录中核对。
- 有经验组只使用提交时选中的经验；无经验组检索数为零。普通建议和蒸馏规则的类型都会展示，因此不能把所有差异单独归因于蒸馏。
- 同一对使用相同生图种子，不同对递增；当前仅 `sd_cpp` 支持。其他生图 API 明确标记种子未控制，仍可进行探索性对比。
- 逐对交替 A→B / B→A 顺序。构思和评价参数保持相同，但服务端随机采样、硬件、模型别名背后的权重等不受严格控制。这里不是完全可复现的科学基准。
- 评价模型只看到图片、题目、风格和艺术要求，看不到实验分组、检索经验、历史分数或构思内容；实验不增加额外评分调用。
- 所有实验作品带 `experiment` 标记，不进入记忆、不参与蒸馏、不推进课程。重新评价、整理历史作品也不能把它们回灌训练数据。
- 实验记录保存每次原始评价和实际注入的规则。之后作品重评不会改写实验结果；新实验才能产生新的比较结果。
- 部分失败保留已完成结果和失败作品链接；进程中断标记 interrupted，不自动重试推理、不把部分结果报告为成功。

每轮冻结配置摘要与经验哈希，完整角色设置沿用内部队列快照。网页不公开 API 地址、环境变量名、凭据或本地模型文件路径。

## 如何解释结果

- 汇总仅使用完整配对。均差为「有经验分数 − 无经验分数」，逐维分数和胜 / 平 / 负同样按配对统计；绝对差 ≤ 0.05 计为平。
- 曲线横轴是独立配对轮次，不是边学习边改写经验的时间轴。实验中冻结经验，避免把后生成的作品当成天然更强。
- 少于 3 个完整配对，显示样本不足。模拟结果、未完整结束、没有实际注入经验均不判断成长。
- 至少 3 对且差值有变化时，报告配对均差的探索性 95% t 区间：均差 ± t(n−1,0.975) × 样本标准差 / √n。假定配对差值近似独立且均值抽样分布适合 t 近似；小样本、单一题目、模型评分的依赖性会削弱解释力。
- 区间全正 / 全负仅称「本题有提升 / 退步迹象」；覆盖零或差值无变化时报告尚未观察到稳定提升。不能据此宣称统计上证明长期能力提升。
- 在已练习题目上的优势可能来自针对性提示，而非泛化。建议用 10 对和多个未参与蒸馏的主题复验，并人工查看作品。模型评分偏宽松时，不应以高分代替人的判断。

## 接口与存储

- `GET /api/v1/painters/{id}/distilled`：当前候选及来源。
- `POST /api/v1/painters/{id}/distilled`：重新蒸馏，不调用模型；运行任务期间禁止。
- `POST /api/v1/painters/{id}/experiments/preview`：预览冻结条件。
- `POST /api/v1/painters/{id}/experiments`：提交持久化任务，需要 `Idempotency-Key`。
- `GET /api/v1/painters/{id}/experiments`：最近 30 次实验，包含摘要与配对作品。

实验请求：`{"topic":"A red apple beside a white ceramic cup","pairs":3}`。API 接受 1–10 对整数。相同请求标识重试返回同一任务，条件变化则 409；继续使用每位画师最多一个任务的队列规则。

SQLite 新增 `distilled_lessons`、`growth_experiments`，兼容原数据。核心实现分别为 `evolution.py`、`experiments.py`，网页组件独立为 `GrowthPanel.tsx`。

自动测试覆盖证据分组、去重与撤回、模拟及实验数据排除、经验冻结、两组隔离、顺序与种子、断点恢复、旧实验不被重评改写、统计结论、任务幂等与接口数据边界。


## 本机真实验收（2026-11-03）

画师「拾光」的两幅历史同题静物作品得分 8.5 与 7.833，提取了一条有来源的候选构图 / 技法建议。网页提交 3 对真实本地模型实验，任务 `722c37dca0994487a0d2183855854d0b`，共 6 幅，无模拟环节，配对生图种子 42、43、44。无经验组为 8.833、8.833、8.000；有经验组为 6.833、6.167、6.833。均分分别 8.555 与 6.611，差值 -1.944，探索性 95% 区间 [-3.810,-0.078]，0 胜 / 0 平 / 3 负。

网页如实报告「本题出现退步迹象」，没有宣称学习成功。人工查看第一对图片，有经验组偏离苹果与白杯的题目；视觉模型反馈文字仍有主体误判，因此分数和区间不能代替看图。当前小模型可能被泛化的构图建议干扰，这只是解释假设，不能由本次单题实验确定因果。6 幅实验作品均未进入训练记忆；实际存储的生图种子、分组与经验引用已逐项核对。

## 风格档案对照与评价核对

实验请求支持 `mode: "style_profile"`（网页可选），原有默认 `memory` 保持兼容。
风格对照关闭两组记忆和生图时的长期目标，基线移除风格档案，学习组使用冻结档案；两组共享原题、配置和配对种子，并按相同的原始目标与风格要求评价。画师保存的长期目标不变。
这是风格档案提示词的消融对照，不是模型权重训练前后的测量。实验作品不写回训练记忆；单对结果不能证明稳定进步。

英文提示词模式保留英文原题，中文原题单独翻译；风格特征单独转换后追加，不允许构思输出覆盖原题。翻译仍输出中文时停止生成。翻译的语义准确度仍依赖模型，应查看作品详情中的最终提示词。

视觉评价先在不提供题目或风格的情况下描述实际像素，再核对具体要求，记录 `met/missed/uncertain` 与证据。核对项从原题和本轮要求固定提取，不允许模型改写；每项单独请求，避免批量输出证据错行。有遗漏时主题分最高 4，无法确认时最高 6；存在任一遗漏或不确定项时其他维度也最高 6，作为保守的交付合规上限，并不等于每项审美能力都下降。反馈保留独立观察和核对证据，旧评价历史不会删除。模型仍可能漏检，不把模型高分当作人类评价或进步证明。

每幅作品需一次独立观察、一次综合评价以及每条固定要求的一次核对调用（最多 14 项）；本地运行会增加等待时间，使用云端模型时也会增加调用费用。任一调用失败均显式失败，不自动重试或写入成功记忆。

网页提供逐种子分数表、配对作品缩略图和冻结档案的参考图。风格描述分衡量文字要求，不是与参考图的视觉相似度；当前生图仅追加最多四条通用技法提示，没有直接参考图条件或权重训练。

实验可附加 `visual_review`，展示助手看图复核、逐种子观察及同图重复评分差异。该复核不覆盖原始评分，也不参与置信区间计算，必须标注非盲评。相同图片重复评分出现明显差异时，应先检查评价可靠性，不能用均分上升宣称学会目标画风。

## 参考图对照评价

生图侧另支持 `mode: "image_reference"`、`reference_index`（档案中的 0–2 索引）、`reference_strength`（大于 0 且不大于 1，默认 0.6）。两组使用相同的最终文字提示词，学习组额外接收参考图像，详见 `LOCAL_ANIME.md`。这与 `style_profile` 的文字档案消融是两种实验，旧记录保持原来的含义。

已完成且有冻结风格档案的实验，可通过网页「参考图对照评价」单独重评。接口为 `POST /api/v1/painters/{painter_id}/experiments/{experiment_id}/reference-review`，使用 `Idempotency-Key`；调用当前视觉评价模型，进入原有串行任务队列。该模型需要支持同时输入最多四张图片（1–3 张参考 + 1 张目标），不支持时显式失败，不退化为只读文字评分。

每张生成图分五次比较线条、上色、光影、眼睛画法、脸部比例；每次都传入参考和目标的真实像素，不提供分组标签、作者身份或旧分数。0–4 分表示本项画法的接近程度，附参考证据、生成图证据、差距和模型自报置信度，不是百分比或经过校准的相似度。用户题目服从度仍由原评价查看。

结果存入实验的 `reference_reviews` 历史，保存模型、参数、量表版本、参考与生成图哈希。每个分项完成即落盘，失败/中断保留已有数据，不改写原作品、原分数或创作记忆。网页提供逐种子对照表、参考缩略图和每张目标图的证据展开。五项均有效才显示该图均分，两张均有效才显示配对均差。

当前保守证据检查会标记差距理由中的发色、眼色、服饰、背景等内容混淆，以及低置信度输出；标记分数保留但排除均分。它不是完整语义验证，可能误报或漏报；未标记也不能保证模型正确。尤其小型本地模型可能看错高光、比例或夸大接近度，应结合原图核对，不能将该分数直接用于训练奖励或成长结论。
