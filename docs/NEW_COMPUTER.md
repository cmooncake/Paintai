# 在另一台 Windows 电脑部署并恢复小笑

本指南适用于 Windows + PowerShell：拉取代码、安装依赖、启动前后端、导入画师数据，再检查恢复结果。首次恢复不需要模型或 API 密钥，也不需要 GPU。

代码和迁移包是两份独立的东西：**Git 只同步代码与文档，画师数据需要另外带走 ZIP 并导入。**

## 1. 在旧电脑准备迁移包

1. 等待当前创作或训练任务结束。
2. 打开旧电脑画室，选择「小笑」。
3. 点击左侧「数据迁移」→「下载迁移包」。
4. 将下载的 ZIP 复制到新电脑，保持 ZIP 格式，不用解压。

2026-11-06 已导出的本地备份名为 `paintai-xiaoxiao-20261106.zip`，原电脑位置是 `D:\Paintai\data\backups\paintai-xiaoxiao-20261106.zip`，约 14.8 MB。这是旧电脑上的文件，不在远程仓库中。网页下载的文件名通常是 `paintai-<画师ID>.zip`，两种文件名均可导入。

如果旧电脑之后新增了学习记录或作品，请重新导出，使用最新迁移包。

## 2. 在新电脑安装运行环境

准备 Git、Python 3.11+、Node.js 22.12+（包含 npm），并确保它们加入 PATH。安装完成后重新打开 PowerShell，逐条检查：

```powershell
git --version
python --version
node --version
npm.cmd --version
```

四条命令都应输出版本号。若提示找不到命令，先解决相应工具的安装或 PATH 问题，再继续。

## 3. 拉取仓库

以下以 `D:\Paintai` 为例；没有 D 盘时，请把后续所有路径换成你的实际安装目录。

首次部署：

```powershell
cd D:\
git clone https://github.com/cmooncake/Paintai.git
cd D:\Paintai
```

如果已经克隆过，只执行这一组：

```powershell
cd D:\Paintai
git pull --ff-only
```

若 Git 提示本地改动或分支分歧，请先保留并整理本地改动，不要用强制重置解决。数据迁移功能自提交 `81319bc` 起提供，请使用包含该提交的 `main` 版本。

## 4. 安装项目依赖

在项目根目录逐条执行，确认上一条成功后再执行下一条：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev,web]"
npm.cmd --prefix web ci
```

此步骤需要联网下载依赖。不需要手动激活虚拟环境，也不要复制旧电脑的 `.venv` 或 `node_modules`。

## 5. 启动网页与 API

在 `D:\Paintai` 执行：

```powershell
.\scripts\start-web.ps1 -Offline
```

看到 `Studio: http://127.0.0.1:5173 | API docs: http://127.0.0.1:8000/docs` 后，在新电脑浏览器打开：

**[http://127.0.0.1:5173/](http://127.0.0.1:5173/)**

脚本在后台分别启动前端（5173）与 API（8000）。这里的 `127.0.0.1` 指当前电脑，请在运行服务的这台电脑上访问。

`-Offline` 无需模型即可导入、浏览历史作品；新创作和新评价使用模拟模型。它不会把导入的历史图片、评价改成模拟结果。不要用此模式判断新创作的真实质量。

### 如果 PowerShell 禁止运行脚本

可以直接开两个 PowerShell 窗口，不必修改系统执行策略。

第一个窗口启动后端：

```powershell
cd D:\Paintai
.\.venv\Scripts\python.exe -m paintai.api --config configs/offline.toml --port 8000
```

第二个窗口启动前端：

```powershell
cd D:\Paintai
npm.cmd --prefix web run dev
```

保持两个窗口打开，再访问同一个网页地址。不要同时使用脚本和手动方式启动两套服务。

## 6. 导入小笑

1. 点击网页左侧「数据迁移」。空白画室也有这个入口，**不需要提前创建小笑**。
2. 在「导入画师」区域选择复制过来的 ZIP。
3. 点击「导入并恢复」，等待成功提示。
4. 网页自动选中小笑，随后可以访问「作品库」「学习」「LoRA 实验」。

导入恢复原标识符，不合并、不覆盖。若提示「此画师已存在」，先检查左侧是否已经有恢复的小笑，不要删除现有数据后盲目重试。每个迁移包最大 256 MB；格式、校验失败时会拒绝导入。

## 8. 日常启动、停止和后续创作

使用脚本部署后，每次重启电脑，在项目目录运行：

```powershell
cd D:\Paintai
.\scripts\start-web.ps1 -Offline
```

停止脚本登记的前后端服务（先等待任务结束）：

```powershell
.\scripts\stop-web.ps1
```

如果是两个窗口手动启动的服务，分别在两个窗口按 `Ctrl+C` 停止；它们不由停止脚本管理。

恢复后的数据库和图片保存在新电脑的 `D:\Paintai\data`。关闭网页或重启电脑不会清空数据，不用重复导入。更换安装目录或电脑前，请重新导出迁移包。

继续真实创作前，在「模型设置」重新配置模型与密钥，或按 [全本地闭环](LOCAL_FULL.md)、[本地二次元生图](LOCAL_ANIME.md)、[LoRA 训练说明](LORA.md) 安装所需资源。API 配置见 [模型配置说明](MODEL_SETTINGS.md)。切换启动配置前先停止原服务；安装好本地资源后可按 [网页画室说明](WEB.md) 启动真实模式。

迁移包不包含 API 密钥、模型服务配置、底模、LoRA 权重、参考原作、待执行任务和训练缓存。文字风格特征与历史参考对照结论保留；再次使用参考图生成或评价需重新上传原作并建立风格档案。迁移范围及接口细节见 [数据迁移说明](TRANSFER.md)。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| 网页打不开 | 确认启动命令成功、访问的是本机 5173 端口；查看项目内 `data/web/web.stderr.log` 和 `data/web/api.stderr.log`。手动启动时看对应窗口输出。 |
| 网页提示后台未连接 | 打开 [API 健康检查](http://127.0.0.1:8000/api/v1/health)，正常应返回 `{"status":"ok"}`；失败时检查后端日志。 |
| 提示端口被占用 | 检查是否已启动另一套 Paintai。关闭自己已确认的旧服务后重试，不要直接结束不明进程。 |
| 提示 API 使用另一配置 | 等任务结束，执行 `stop-web.ps1`，再用选定模式启动。 |
| 没有「数据迁移」入口 | 确认拉取了最新 `main`；停止前后端后重新启动并刷新网页。 |
| 导入后不能真实生成 | 数据恢复不包含模型和密钥，先到「模型设置」配置并检查服务。历史数据仍可浏览。 |
| 导入失败或提示文件损坏 | 确认选择的是网页导出的 ZIP，不是 GitHub 源码 ZIP；重新复制或从旧电脑重新导出，不要手动改包内文件。 |
