# 琪光：琪亚娜终焉半身照提示词修复对照

日期：2026-11-09。此记录检验提示词编译与评价修复，不是 LoRA 训练或风格成长证明。

## 已确认的问题

- 原图实际执行提示词保留了完整题目，不能归因为题目丢失；但属性保护仅识别白发和背景，遗漏 `violet eyes`、双色服装与半身取景。
- 评价分句把 `white and purple dress` 拆开，无法完整核对服装；带题目的小视觉模型还会将不支持的要求判为满足，并给出与盲看观察矛盾的赞美。
- Animagine 官方采用标签式训练和提示词组织。原图较长的自然语言描述、重复属性与以脸部为主的技巧词可能削弱人物及取景控制；单次对照不能分别确定各因素的因果贡献。

## 控制条件与改动

两图原题相同：琪亚娜终焉形态，独立人物、完整头部的半身构图、白色长发、紫眼及青色虹膜高光、白紫服装配黑色花饰、微笑、胸前手势、简洁蓝灰背景及柔和侧光。

两图均为 Animagine XL 4.0 Opt，种子 42，768×1024，28 步，CFG 5，Euler A，discrete scheduler，CLIP skip 2，CPU 8 线程。画师风格档案与四个技巧词保持相同，没有 LoRA 或参考图生图条件。修复版不检索新产生的记忆。

修复版改用标签式组织，适度加权白发、双色服装和半身范围，补充冲突发色/取景的负面词。一次未完成采样因发现虹膜高光在编译后被漏读、产生冲突负面词而中止；修正并通过命令一致性测试后，仍以种子 42 重跑，没有换种子挑图。

## 可见结果与限制

| 项目 | 修复前 | 修复后 |
|---|---|---|
| 发色与眼色 | 深蓝黑发、青蓝眼 | 白发与紫眼明显恢复 |
| 取景 | 脸部大特写、头顶裁切 | 躯干到腰部可见，头顶留白仍不足 |
| 服装 | 终焉服装不可辨认 | 白紫衣身和黑色花饰出现，配色比例、结构与饰物位置仍不准确 |
| 手势 | 不可见 | 胸前手势仍未实现 |
| 画法 | 高光生硬、虹膜简化 | 人物可读性改善，但线条、虹膜与光影仍未达到官方参考细节 |

两图按 `blind-portrait-audit-v4` 重评：主题分 4→6，构图分 4→6（满分 10）。新规则标出了修复版服装与手势证据不足，删除了“完全还原”的自由总结；本地视觉模型对命名角色身份仍偏乐观，分数不应代替看图验收。另保存两张官方参考图与生成图的五维多图评价，保留置信度与证据不足标记，不将其换算为相似度百分比。

结论：本种子下人物属性和取景明显改善，服装仅部分改善；不能声称终焉造型已经准确还原，也不能证明已经学会官方画风。
